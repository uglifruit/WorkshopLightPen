# LIGHTPEN

A program card for the [Music Thing Modular Workshop System Computer](https://github.com/TomWhitwell/Workshop_Computer).

Status: early in development. Details to follow as the design firms up.

## Building

Requires the Raspberry Pi Pico SDK (see `pico_sdk_import.cmake`).

```
mkdir build
cd build
cmake ..
make
```
